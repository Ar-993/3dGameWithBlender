# От аудиоменеджера до коллайдеров, винтовки, звуков и сигилей

## 1. Упростить коллайдеры предметов

**Было.** `RoundedBoxShape` строил решётку из пересекающихся сфер по размерам модели. Узкий длинный предмет требовал много сфер. При падении и вращении движок проверял контакты и движение каждой сферы отдельно.

**Стало.** Для конкретного типа предмета можно описать одну или несколько капсул. Капсула — отрезок с радиусом вокруг него. Одна длинная капсула даёт сплошную форму от одного конца до другого. У фонарика осталась одна капсула, у пистолета две. У предметов без явной формы сохраняется прежняя схема. Геометрия уровня, которую использует коллизия, остаётся треугольной.

### Вставка в каталог

В `Content/Items/items.json` добавь этот блок *внутрь существующего объекта* с `"id": "flashlight"`. Поставь запятую между соседними полями.

~~~json
"collider": {
  "capsules": [
    {
      "start": [0, 0.03, -0.114],
      "end": [0, 0.03, 0.114],
      "radius": 0.031
    }
  ]
}
~~~

Здесь `Y` направлен вверх, ось капсулы идёт вдоль `Z`, а радиус покрывает толщину фонарика. `start` и `end` измеряются **после** подгонки модели к `height`, от нижнего центра предмета. Нижняя часть капсулы доходит до `0.03 - 0.031`. Если поменяешь `height` или развернёшь геометрию при импорте, перепроверь эти числа. При совпадающих `start` и `end` форма становится сферой.

Для пистолета добавь этот блок внутрь объекта с `"id": "colt"`. Первая капсула покрывает корпус, вторая — рукоятку.

~~~json
"collider": {
  "capsules": [
    { "start": [-0.137, 0.18, 0], "end": [0.115, 0.18, 0], "radius": 0.04 },
    { "start": [0.105, 0.136, 0], "end": [0.137, 0.038, 0], "radius": 0.041 }
  ]
}
~~~

### Как код доходит до физики

1. `Items/ItemCatalogData.cs` читает `collider.capsules`. `ItemCatalog.cs` передаёт эту форму в `ItemDefinition` вместе с размерами, настройками физики и удержания.
2. `ItemInstance` создаёт тело из определения. Внутри `RigidBodyShape` от концов капсул вычитается `LocalCenter`. Так тело вращается вокруг своего центра масс, хотя координаты в JSON удобнее измерять от основания модели.
3. `BodyCollision` переводит концы капсулы в мировые координаты. `LevelItemWorld` через `ICapsuleCollisionWorld` передаёт оба конца, их движение и радиус в `Level.RigidItemCapsuleCollision.cs`. Проверяется весь отрезок, поэтому тонкая стенка может остановить длинный предмет даже при контакте с его серединой.
4. Форму и её настройки хранит определение типа. Положение, скорость и состояние покоя хранит экземпляр тела. Два одинаковых фонарика падают независимо.

Вставка, которая связывает определение с телом, выглядит так. Это строка из конструктора `ItemInstance` после добавления `ItemCollider` и обновления `RigidBody`:

~~~csharp
Body = new RigidBody(bottomPosition, definition.Radius, definition.Height,
    definition.HalfExtents, definition.BodySettings, definition.Collider);
~~~

**Проверка.** Брось фонарик на пол, потом брось длинный предмет в стену боком. Он должен остановиться при касании, упасть и затихнуть. Если модель заметно висит над полом, уменьши радиус или подними ось капсулы внутри модели. Если торец уходит в стену раньше контакта, удлини капсулу. Для формы с выступом добавляй вторую капсулу только на выступ. Уменьшение числа форм снижает количество физических запросов, а итоговый FPS зависит и от рендеринга уровня.

~~~csharp
using System.Numerics;

namespace Ars3D.Items.Physics;

/// <summary>Капсула в координатах масштабированной модели, отсчитанных от нижней точки привязки.</summary>
public readonly record struct ColliderCapsule(Vector3 Start, Vector3 End, float Radius);

/// <summary>Неизменяемый составной коллайдер, общий для экземпляров одного типа предмета.</summary>
public sealed class ItemCollider
{
    public IReadOnlyList<ColliderCapsule> Capsules { get; }

    public ItemCollider(IEnumerable<ColliderCapsule> capsules)
    {
        ArgumentNullException.ThrowIfNull(capsules);
        ColliderCapsule[] parts = capsules.ToArray();
        if (parts.Length == 0)
            throw new ArgumentException("A collider needs at least one capsule.", nameof(capsules));
        foreach (ColliderCapsule part in parts)
            if (!RigidBody.Finite(part.Start) || !RigidBody.Finite(part.End) ||
                !float.IsFinite(part.Radius) || part.Radius <= 0f)
                throw new ArgumentException("Capsule endpoints must be finite and radius positive.", nameof(capsules));
        Capsules = Array.AsReadOnly(parts);
    }
}
~~~

#### Создай `Libraries/Ars3D.Items/Physics/RigidBodyShape.cs`

После вставок в `RigidBody` и `BodyCollision` удали прежний файл `Libraries/Ars3D.Items/Physics/RoundedBoxShape.cs`.

~~~csharp
using System;
using System.Numerics;
using Ars3D.Items.Geometry;

namespace Ars3D.Items.Physics;

// Все части коллайдера движутся вокруг общего центра массы.
// Для предмета без заданных капсул сохраняется исходная сетка сфер.
internal sealed class RigidBodyShape
{
    public Vector3 HalfExtents { get; }
    public Vector3 LocalCenter { get; }
    public float BoundingRadius { get; }
    public ColliderCapsule[] Parts { get; }

    public RigidBodyShape(float radius, float height, Vector3? halfExtents, ItemCollider? collider)
    {
        if (!float.IsFinite(radius) || radius <= 0f)
            throw new ArgumentOutOfRangeException(nameof(radius));
        if (!float.IsFinite(height) || height <= 0f)
            throw new ArgumentOutOfRangeException(nameof(height));
        HalfExtents = halfExtents ?? new Vector3(radius, height * 0.5f, radius);
        if (!RigidBody.Finite(HalfExtents) || HalfExtents.X <= 0f || HalfExtents.Y <= 0f || HalfExtents.Z <= 0f)
            throw new ArgumentOutOfRangeException(nameof(halfExtents));
        LocalCenter = Vector3.UnitY * (height * 0.5f);
        if (collider is null)
        {
            float sphereRadius = MathF.Min(HalfExtents.X, MathF.Min(HalfExtents.Y, HalfExtents.Z));
            Parts = CreateOffsets(HalfExtents, sphereRadius)
                .Select(offset => new ColliderCapsule(offset, offset, sphereRadius)).ToArray();
            BoundingRadius = HalfExtents.Length();
        }
        else
        {
            Parts = collider.Capsules.Select(part => part with
            {
                Start = part.Start - LocalCenter,
                End = part.End - LocalCenter
            }).ToArray();
            BoundingRadius = Parts.Max(part => MathF.Max(part.Start.Length(), part.End.Length()) + part.Radius);
        }
    }

    public Aabb GetBounds(Vector3 center, Quaternion orientation)
    {
        Vector3 minimum = new(float.MaxValue);
        Vector3 maximum = new(float.MinValue);
        foreach (ColliderCapsule part in Parts)
        {
            Vector3 extent = new(part.Radius);
            Vector3 start = center + Vector3.Transform(part.Start, orientation);
            Vector3 end = center + Vector3.Transform(part.End, orientation);
            minimum = Vector3.Min(minimum, Vector3.Min(start, end) - extent);
            maximum = Vector3.Max(maximum, Vector3.Max(start, end) + extent);
        }
        return new(minimum, maximum);
    }

    private static Vector3[] CreateOffsets(Vector3 halfExtents, float radius)
    {
        Vector3 interior = Vector3.Max(halfExtents - new Vector3(radius), Vector3.Zero);
        int countX = Count(interior.X);
        int countY = Count(interior.Y);
        int countZ = Count(interior.Z);
        var offsets = new Vector3[countX * countY * countZ];
        int index = 0;
        for (int x = 0; x < countX; x++)
        {
            for (int y = 0; y < countY; y++)
            {
                for (int z = 0; z < countZ; z++)
                {
                    offsets[index++] = new Vector3(
                        Coordinate(x, countX, interior.X),
                        Coordinate(y, countY, interior.Y),
                        Coordinate(z, countZ, interior.Z));
                }
            }
        }
        return offsets;

        int Count(float extent) =>
            extent < 0.000001f ? 1 : (int)MathF.Ceiling(2f * extent / (radius * 1.35f)) + 1;
        static float Coordinate(int index, int count, float extent) =>
            count == 1 ? 0f : -extent + 2f * extent * index / (count - 1);
    }
}
~~~

#### Создай `Levels/Level.RigidItemCapsuleCollision.cs`

`SweepRigidItemCapsule` сначала ограничивает поиск объёмом движения, а затем вызывает `FindFirstCapsuleHit`. Тот отбрасывает стыки треугольников и контакты, от которых капсула удаляется. `CastMovingCapsuleTriangle` ищет момент касания одного треугольника. При почти одновременных касаниях выбирается нормаль, сильнее направленная вверх, а движение ограничивается самым ранним временем.

~~~csharp
using Microsoft.Xna.Framework;

namespace _3DLight;

public partial class Level
{
    private readonly List<(TriangleCollider Triangle, CapsuleCollision.Contact Contact)> rigidCapsuleCandidates = [];

    internal bool SweepRigidItemCapsule(Vector3 start, Vector3 end, Vector3 startMovement,
        Vector3 endMovement, float radius, Vector3 startVelocity, Vector3 endVelocity,
        out RigidItemSweepHit result)
    {
        float maximumMovement = MathF.Max(startMovement.Length(), endMovement.Length());
        if (maximumMovement < 0.000001f)
        {
            result = default;
            return false;
        }

        var sweep = new CapsuleSweep(start, end, startMovement, endMovement, radius, startVelocity, endVelocity);
        GatherCapsuleSweepCandidates(GetCapsuleSweepBounds(sweep), start, end, radius);

        float timeTolerance = 0.00001f / maximumMovement;
        RigidItemSweepHit? firstHit = FindFirstCapsuleHit(sweep, timeTolerance);
        result = firstHit.GetValueOrDefault();
        return firstHit.HasValue;
    }

    private static BoundingBox GetCapsuleSweepBounds(CapsuleSweep sweep)
    {
        Vector3 finalStart = sweep.Start + sweep.StartMovement;
        Vector3 finalEnd = sweep.End + sweep.EndMovement;
        Vector3 min = Vector3.Min(Vector3.Min(sweep.Start, sweep.End), Vector3.Min(finalStart, finalEnd));
        Vector3 max = Vector3.Max(Vector3.Max(sweep.Start, sweep.End), Vector3.Max(finalStart, finalEnd));
        Vector3 padding = new(sweep.Radius + CapsuleCollision.SkinWidth + RigidContactMargin);
        return new BoundingBox(min - padding, max + padding);
    }

    private RigidItemSweepHit? FindFirstCapsuleHit(CapsuleSweep sweep, float timeTolerance)
    {
        RigidItemSweepHit? firstHit = null;
        foreach (var (triangle, initialContact) in rigidCapsuleCandidates)
        {
            if (IsHiddenRigidEdge(initialContact, triangle) || IsSeparatingCapsuleContact(sweep, initialContact))
                continue;

            float firstTime = firstHit?.Fraction ?? 1f;
            float castLimit = MathF.Min(1f, firstTime + timeTolerance);
            if (!CastMovingCapsuleTriangle(sweep, triangle, castLimit, out float time, out var contact))
                continue;

            if (firstHit is { } previous && !IsPreferredCapsuleHit(time, contact, previous, timeTolerance))
                continue;

            // При близких попаданиях сохраняем самое раннее время движения.
            float fraction = MathF.Min(firstTime, time);
            firstHit = new RigidItemSweepHit(fraction, new(contact.SurfacePoint, contact.Normal, contact.Penetration));
        }

        return firstHit;
    }

    private static bool IsPreferredCapsuleHit(float time, CapsuleCollision.Contact contact,
        RigidItemSweepHit previous, float tolerance)
    {
        // При почти одновременных попаданиях предпочитаем нормаль, направленную ближе к вертикали вверх.
        return time < previous.Fraction - tolerance ||
            (MathF.Abs(time - previous.Fraction) <= tolerance && contact.Normal.Y > previous.Contact.Normal.Y);
    }

    private void GatherCapsuleSweepCandidates(BoundingBox bounds, Vector3 start, Vector3 end, float radius)
    {
        rigidCapsuleCandidates.Clear();
        rigidSphereContacts.Clear();
        foreach (TriangleCollider triangle in GetCollisionCandidates(bounds))
        {
            var contact = CapsuleCollision.GetContact(start, end, radius, triangle);
            rigidCapsuleCandidates.Add((triangle, contact));
            if (contact.Penetration >= -RigidContactMargin)
                rigidSphereContacts.Add((contact, triangle));
        }
    }

    private static bool IsSeparatingCapsuleContact(CapsuleSweep sweep, CapsuleCollision.Contact contact)
    {
        if (contact.Penetration < -RigidContactMargin)
            return false;

        float amount = sweep.AmountAlongAxis(contact.AxisPoint);
        Vector3 velocity = Vector3.Lerp(sweep.StartVelocity, sweep.EndVelocity, amount);
        Vector3 movement = Vector3.Lerp(sweep.StartMovement, sweep.EndMovement, amount);
        return Vector3.Dot(velocity, contact.Normal) >= -0.002f &&
            Vector3.Dot(movement, contact.Normal) >= -CapsuleCollision.SkinWidth * 0.5f;
    }

    private static bool CastMovingCapsuleTriangle(CapsuleSweep sweep, TriangleCollider triangle,
        float maximumTime, out float time, out CapsuleCollision.Contact contact)
    {
        time = 0f;
        contact = default;
        for (int iteration = 0; iteration < 48; iteration++)
        {
            Vector3 start = sweep.Start + sweep.StartMovement * time;
            Vector3 end = sweep.End + sweep.EndMovement * time;
            contact = CapsuleCollision.GetContact(start, end, sweep.Radius, triangle);

            // Самый быстро приближающийся конец ограничивает скорость сближения всего отрезка.
            float closing = MathF.Max(-Vector3.Dot(sweep.StartMovement, contact.Normal),
                -Vector3.Dot(sweep.EndMovement, contact.Normal));
            if (closing <= 0.0000001f)
                return false;

            float gap = contact.Distance - sweep.Radius - CapsuleCollision.SkinWidth;
            if (gap <= 0.00001f)
                return true;

            float nextTime = time + gap / closing;
            if (nextTime > maximumTime)
                return false;
            if (nextTime <= time)
                return true;

            time = nextTime;
        }

        // При исчерпании итераций останавливаем тело на последней рассчитанной позиции.
        return true;
    }

    internal void GetRigidItemCapsuleContacts(Vector3 start, Vector3 end, float radius,
        List<RigidItemContact> contacts)
    {
        Vector3 extent = new(radius + CapsuleCollision.SkinWidth + RigidContactMargin);
        rigidSphereContacts.Clear();
        foreach (TriangleCollider triangle in GetCollisionCandidates(new(
            Vector3.Min(start, end) - extent, Vector3.Max(start, end) + extent)))
        {
            Add(CapsuleCollision.GetContact(start, end, radius, triangle), triangle);
            // Контакты обоих концов дают капсуле устойчивую опору на плоскости.
            Add(CapsuleCollision.GetContact(start, start, radius, triangle), triangle);
            Add(CapsuleCollision.GetContact(end, end, radius, triangle), triangle);
        }
        AppendVisibleRigidContacts(contacts);

        void Add(CapsuleCollision.Contact contact, TriangleCollider triangle)
        {
            if (contact.Penetration >= -RigidContactMargin)
                rigidSphereContacts.Add((contact, triangle));
        }
    }

    private readonly record struct CapsuleSweep(
        Vector3 Start,
        Vector3 End,
        Vector3 StartMovement,
        Vector3 EndMovement,
        float Radius,
        Vector3 StartVelocity,
        Vector3 EndVelocity)
    {
        public float AmountAlongAxis(Vector3 point)
        {
            Vector3 axis = End - Start;
            float lengthSquared = axis.LengthSquared();
            if (lengthSquared <= 0.000000000001f)
                return 0f;

            return MathHelper.Clamp(Vector3.Dot(point - Start, axis) / lengthSquared, 0f, 1f);
        }
    }
}
~~~

~~~csharp
using Microsoft.Xna.Framework;

namespace _3DLight.Items;

// Боезапас хранится у экземпляра оружия и сохраняется после выбрасывания и подбора.
internal sealed class WeaponState
{
    public WeaponData Definition { get; }
    public int LoadedRounds { get; private set; }
    public int ReserveRounds { get; private set; }
    private float ReloadRemaining { get; set; }
    private float Cooldown { get; set; }
    private float Kick { get; set; }
    public bool IsReloading => ReloadRemaining > 0f;
    public Vector3 Muzzle { get; }

    public WeaponState(WeaponData definition)
    {
        definition.Validate();
        Definition = definition;
        LoadedRounds = definition.MagazineSize;
        ReserveRounds = definition.ReserveRounds;
        Muzzle = ItemMath.ToGame(ItemCatalogVectors.Read(definition.Muzzle, "muzzle"));
    }

    public void Update(float seconds, bool equipped)
    {
        seconds = Math.Max(0f, seconds);
        Cooldown = Math.Max(0f, Cooldown - seconds);
        Kick = Math.Max(0f, Kick - seconds * 9f);
        if (!equipped)
        {
            ReloadRemaining = 0f;
            return;
        }
        if (!IsReloading)
            return;
        ReloadRemaining = Math.Max(0f, ReloadRemaining - seconds);
        if (ReloadRemaining == 0f)
        {
            int count = Math.Min(Definition.MagazineSize - LoadedRounds, ReserveRounds);
            LoadedRounds += count;
            ReserveRounds -= count;
        }
    }

    public bool TryReload()
    {
        if (IsReloading || LoadedRounds == Definition.MagazineSize || ReserveRounds == 0)
            return false;
        ReloadRemaining = Definition.ReloadSeconds;
        return true;
    }

    public bool TryFire()
    {
        if (IsReloading || Cooldown > 0f || LoadedRounds == 0)
            return false;
        LoadedRounds--;
        Cooldown = Definition.FireInterval;
        Kick = 1f;
        return true;
    }

    public Matrix HeldAnimation
    {
        get
        {
            float reload = IsReloading
                ? MathF.Sin(MathF.PI * ReloadRemaining / Definition.ReloadSeconds) : 0f;
            return Matrix.CreateRotationX(Kick * 0.045f - reload * 0.55f) *
                Matrix.CreateTranslation(0f, -reload * 0.15f, Kick * 0.055f);
        }
    }
}

internal sealed class WeaponData
{
    public float[] Muzzle { get; init; } = [0f, 0f, -0.5f];
    public int MagazineSize { get; init; } = 5;
    public int ReserveRounds { get; init; } = 25;
    public int Damage { get; init; } = 40;
    public float Range { get; init; } = 120f;
    public float FireInterval { get; init; } = 0.65f;
    public float ReloadSeconds { get; init; } = 1.8f;

    public void Validate()
    {
        if (MagazineSize <= 0 || ReserveRounds < 0 || Damage <= 0 ||
            !float.IsFinite(Range) || Range <= 0f ||
            !float.IsFinite(FireInterval) || FireInterval <= 0f ||
            !float.IsFinite(ReloadSeconds) || ReloadSeconds <= 0f)
            throw new InvalidDataException("Invalid weapon settings in item catalog.");
    }
}
~~~

~~~csharp
using _3DLight.Items;
using Microsoft.Xna.Framework;

namespace _3DLight.Gameplay;

internal readonly record struct WeaponHit(Vector3 Position, bool HitTarget);

internal static class WeaponRaycast
{
    public static WeaponHit Cast(Level level, Vector3 origin, Vector3 direction,
        float range, BoundingBox? target)
    {
        if (direction.LengthSquared() <= 0.00000001f || range <= 0f)
            return new(origin, false);
        direction.Normalize();
        float distance = range;
        bool targetHit = false;
        if (level.ItemWorld.SweepSphere(ItemMath.ToLibrary(origin),
                ItemMath.ToLibrary(direction * range), 0.005f, ItemMath.ToLibrary(direction), out var wall))
            distance = range * wall.Fraction;
        if (target is { } bounds && new Ray(origin, direction).Intersects(bounds) is { } targetDistance &&
            targetDistance < distance)
        {
            distance = targetDistance;
            targetHit = true;
        }
        return new(origin + direction * distance, targetHit);
    }
}
~~~

~~~csharp
using _3DLight.Items;
using Camera;
using Items;
using Microsoft.Xna.Framework;
using Microsoft.Xna.Framework.Graphics;

namespace _3DLight.Gameplay;

internal sealed class PlayerWeaponSystem : IDisposable
{
    private const float TraceDuration = 0.10f;
    private readonly GraphicsDevice graphics;
    private readonly BasicEffect effect;
    private readonly AudioSystem? audio;
    private float traceRemaining;
    private Vector3 shotOrigin;
    private Vector3 shotEnd;
    private bool hitTarget;

    public PlayerWeaponSystem(GraphicsDevice graphics, AudioSystem? audio)
    {
        this.graphics = graphics;
        this.audio = audio;
        effect = new BasicEffect(graphics) { VertexColorEnabled = true, LightingEnabled = false };
    }

    public void Update(float seconds, ItemInteraction inventory, FirstPersonCamera camera,
        Level level, Player player, Skeleton skeleton, bool firePressed, bool reloadPressed)
    {
        traceRemaining = Math.Max(0f, traceRemaining - seconds);
        WorldItem? held = player.IsDead ? null : inventory.HeldItem;
        foreach (WorldItem item in inventory.Items)
            item.Weapon?.Update(seconds, item == held);

        if (held?.Weapon is not { } weapon)
            return;
        if (reloadPressed && weapon.TryReload())
            audio?.Play("reload");
        if (firePressed && weapon.TryFire())
            Fire(weapon, inventory, camera, level, skeleton);
    }

    private void Fire(WeaponState weapon, ItemInteraction inventory, FirstPersonCamera camera,
        Level level, Skeleton skeleton)
    {
        audio?.Play("shot");

        var pose = inventory.GetHeldPose(camera.Position, camera.Forward);
        Vector3 muzzle = GetMuzzlePosition(weapon, pose);
        (shotOrigin, WeaponHit shot) = TraceShot(level, camera, muzzle, weapon.Definition.Range, skeleton);
        shotEnd = shot.Position;
        hitTarget = shot.HitTarget;
        traceRemaining = TraceDuration;
        if (hitTarget)
            skeleton.TakeDamage(weapon.Definition.Damage);
    }

    private static (Vector3 Origin, WeaponHit Hit) TraceShot(
        Level level, FirstPersonCamera camera, Vector3 muzzle, float range, Skeleton skeleton)
    {
        if (!level.HasItemLineOfSight(camera.Position, muzzle))
        {
            Vector3 toMuzzle = muzzle - camera.Position;
            WeaponHit obstruction = WeaponRaycast.Cast(level, camera.Position, toMuzzle, toMuzzle.Length(), null);
            return (obstruction.Position, obstruction);
        }

        BoundingBox? target = skeleton.IsDead ? null : GetTargetBounds(skeleton.Position);
        // Луч камеры выбирает цель, а выстрел идёт к ней от дула.
        WeaponHit aim = WeaponRaycast.Cast(level, camera.Position, camera.Forward, range, target);
        Vector3 direction = aim.Position - muzzle;
        float shotRange = Math.Min(direction.Length() + 0.02f, range);
        return (muzzle, WeaponRaycast.Cast(level, muzzle, direction, shotRange, target));
    }

    private static BoundingBox GetTargetBounds(Vector3 feet)
    {
        const float radius = GameplayCharacters.CharacterCollisionRadius;
        const float height = GameplayCharacters.CharacterCollisionHeight;
        return new BoundingBox(feet - new Vector3(radius, 0f, radius), feet + new Vector3(radius, height, radius));
    }

    internal static Vector3 GetMuzzlePosition(WeaponState weapon, Ars3D.Items.ItemPose pose) =>
        Vector3.Transform(weapon.Muzzle, weapon.HeldAnimation * ItemMath.ToGame(pose.ToMatrix()));

    public void Draw(Matrix view, Matrix projection)
    {
        if (traceRemaining <= 0f)
            return;

        effect.View = view;
        effect.Projection = projection;
        effect.World = Matrix.Identity;
        Matrix cameraWorld = Matrix.Invert(view);
        Vector3 right = cameraWorld.Right * 0.055f;
        Vector3 up = cameraWorld.Up * 0.055f;
        BlendState blend = graphics.BlendState;
        DepthStencilState depth = graphics.DepthStencilState;
        try
        {
            graphics.BlendState = BlendState.AlphaBlend;
            graphics.DepthStencilState = DepthStencilState.None;
            foreach (EffectPass pass in effect.CurrentTechnique.Passes)
            {
                pass.Apply();
                DrawTrace(right, up);
            }
        }
        finally
        {
            graphics.BlendState = blend;
            graphics.DepthStencilState = depth;
        }
    }

    private void DrawTrace(Vector3 right, Vector3 up)
    {
        Color color = Color.Gold * (traceRemaining / TraceDuration);
        VertexPositionColor[] line = [new(shotOrigin, color), new(shotEnd, color)];
        graphics.DrawUserPrimitives(PrimitiveType.LineList, line, 0, 1);
        if (traceRemaining > 0.045f)
            DrawMuzzleFlash(right, up);
        if (hitTarget)
            DrawHitMarker(right, up);
    }

    private void DrawMuzzleFlash(Vector3 right, Vector3 up)
    {
        VertexPositionColor[] flash =
        [
            new(shotOrigin - right, Color.Orange), new(shotOrigin + up, Color.LightYellow),
            new(shotOrigin + right, Color.Orange),
            new(shotOrigin - right, Color.Orange), new(shotOrigin + right, Color.Orange),
            new(shotOrigin - up, Color.LightYellow)
        ];
        graphics.DrawUserPrimitives(PrimitiveType.TriangleList, flash, 0, 2);
    }

    private void DrawHitMarker(Vector3 right, Vector3 up)
    {
        Color hit = Color.OrangeRed;
        VertexPositionColor[] marker =
        [
            new(shotEnd - right - up, hit), new(shotEnd + right + up, hit),
            new(shotEnd - right + up, hit), new(shotEnd + right - up, hit)
        ];
        graphics.DrawUserPrimitives(PrimitiveType.LineList, marker, 0, 2);
    }

    public void Dispose() => effect.Dispose();
}
~~~

~~~csharp
// Один FBX может содержать несколько предметов. Извлекаем только нужный узел и его потомков.
static ModelData ExtractStaticItem(ModelData source, string rootName, float[] rotationDegrees)
{
    int root = source.Nodes.FindIndex(node => node.Name.Equals(rootName, StringComparison.OrdinalIgnoreCase));
    if (root < 0)
        throw new InvalidDataException($"Item root '{rootName}' was not found.");

    Matrix4x4 rotation = ItemRotation(rotationDegrees);
    (Matrix4x4[] global, bool[] included) = FindSubtree(source, root);
    MeshData[] meshes = source.Meshes.Where(mesh => included[mesh.Node]).ToArray();
    if (meshes.Length == 0 || meshes.Any(mesh => mesh.Bones.Length != 0))
        throw new InvalidDataException($"'{rootName}' must contain static item meshes.");

    VertexData[][] vertices = meshes.Select(mesh =>
        BakeVertices(mesh, global[mesh.Node] * rotation)).ToArray();

    ModelData result = AssembleStaticItem(rootName, meshes, vertices);
    Console.WriteLine($"  Extracted '{rootName}': {result.Meshes.Count} meshes, no bones required.");
    return result;
}

static Matrix4x4 ItemRotation(float[] degrees)
{
    if (degrees.Length != 3 || degrees.Any(value => !float.IsFinite(value)))
        throw new InvalidDataException("rotationDegrees needs three finite numbers.");

    const float toRadians = MathF.PI / 180f;
    return Matrix4x4.CreateRotationX(degrees[0] * toRadians) *
        Matrix4x4.CreateRotationY(degrees[1] * toRadians) *
        Matrix4x4.CreateRotationZ(degrees[2] * toRadians);
}

static ModelData AssembleStaticItem(string rootName, MeshData[] meshes, VertexData[][] vertices)
{
    // Нижний центр модели становится точкой (0, 0, 0) в системе координат предмета.
    Vector3 pivot = BottomCenter(vertices.SelectMany(mesh => mesh));
    var result = new ModelData();
    result.Nodes.Add(new(rootName, -1, Matrix4x4.Identity));
    for (int index = 0; index < meshes.Length; index++)
    {
        MeshData mesh = meshes[index];
        result.Meshes.Add(new MeshData
        {
            Name = mesh.Name, Node = 0, TextureName = mesh.TextureName,
            MaterialName = mesh.MaterialName, MaterialOpacity = mesh.MaterialOpacity,
            Vertices = vertices[index].Select(vertex => vertex with { Position = vertex.Position - pivot }).ToArray(),
            Indices = mesh.Indices
        });
    }
    return result;
}

static (Matrix4x4[] Global, bool[] Included) FindSubtree(ModelData source, int root)
{
    var global = new Matrix4x4[source.Nodes.Count];
    var included = new bool[source.Nodes.Count];
    for (int index = 0; index < source.Nodes.Count; index++)
    {
        NodeData node = source.Nodes[index];
        global[index] = node.Parent < 0 ? node.Bind : node.Bind * global[node.Parent];
        included[index] = index == root || (node.Parent >= 0 && included[node.Parent]);
    }
    return (global, included);
}

static VertexData[] BakeVertices(MeshData mesh, Matrix4x4 transform)
{
    if (!Matrix4x4.Invert(transform, out Matrix4x4 inverse))
        throw new InvalidDataException($"Item mesh '{mesh.Name}' contains a non-invertible transform.");

    // При неравномерном масштабе нормалям нужна обратная транспонированная матрица.
    Matrix4x4 normalTransform = Matrix4x4.Transpose(inverse);
    return mesh.Vertices.Select(vertex => vertex with
    {
        Position = Vector3.Transform(vertex.Position, transform),
        Normal = Vector3.Normalize(Vector3.TransformNormal(vertex.Normal, normalTransform))
    }).ToArray();
}

static Vector3 BottomCenter(IEnumerable<VertexData> vertices)
{
    Vector3 minimum = new(float.PositiveInfinity);
    Vector3 maximum = new(float.NegativeInfinity);
    foreach (VertexData vertex in vertices)
    {
        minimum = Vector3.Min(minimum, vertex.Position);
        maximum = Vector3.Max(maximum, vertex.Position);
    }
    return new((minimum.X + maximum.X) * 0.5f, minimum.Y, (minimum.Z + maximum.Z) * 0.5f);
}
~~~

### Где брать свои файлы

- Для меню, подбора и реплики подойдут короткие щелчки или сигналы из набора CC0. [Kenney Interface Sounds](https://kenney.nl/assets/interface-sounds)
- Для двери и механического щелчка перезарядки подойдут короткие удары или звуки материалов. Набор помечен CC0. [Kenney Impact Sounds](https://kenney.nl/assets/impact-sounds)
- Для стилизованного игрового выстрела можно взять короткий синтезированный звук из набора CC0. [Kenney Digital Audio](https://kenney.nl/assets/digital-audio)
- Если захочешь заменить фоновый трек, у Cleyton Kauffman есть 48-секундная атмосферная петля CC0 с версией OGG. [Ambient Horror Track 01](https://opengameart.org/content/ambient-horror-track-01)

Импортируй скачанный клип в Audacity, обрежь лишнюю тишину и выбери **Файл → Экспорт аудио**. Для формата выбери **WAV**, для кодировки — **Signed 16-bit PCM**. Сохрани его в `Content/Audio` под именем из таблицы. Сохрани ссылку на исходный набор и имя автора рядом со своими заметками об ассетах.

Для замены фоновой петли оставь формат OGG Vorbis и имя, которое указано в `AudioSystem.StartMusic`. В текущем коде это `Surveillance.ogg`. Эффекты читает `SoundEffect.FromStream`, музыку — `Song.FromUri` и `MediaPlayer`. [MonoGame SoundEffect](https://docs.monogame.net/api/Microsoft.Xna.Framework.Audio.SoundEffect.html) · [MonoGame Song](https://docs.monogame.net/api/Microsoft.Xna.Framework.Media.Song.html)

В `PlayerWeaponSystem.Update` вызов `TryFire` проверяет патроны и интервал. При успехе вызывается `Fire`. В начале `Fire` стоит `audio?.Play("shot")`, поэтому пустой магазин не проигрывает звук выстрела.

~~~csharp
if (firePressed && weapon.TryFire())
    Fire(weapon, inventory, camera, level, skeleton);
~~~

`Play("shot")` ищет имя без расширения и проигрывает эффект с громкостью `MasterVolume * EffectsVolume`. При изменении `Master` или `Music` уже играющий трек получает новое значение `MasterVolume * MusicVolume` через `MediaPlayer.Volume`. Аудиоменеджер остаётся общим при смене сцен. Значения, выбранные в меню, живут до закрытия игры, а начальные берутся из `audio.json`.

**Проверка.** Установи `Music` в 0 и проверь, что меню продолжает издавать звуки. Верни музыку и выставь `Effects` в 0. Трек должен остаться слышен, а следующие действия стать тихими. `Master` в 0 глушит оба канала. Если музыка есть, а эффекта нет, начни с имени WAV и проверь его в `bin/Debug/net8.0/Content/Audio`. Маска загрузчика эффектов должна оставаться `*.wav`, иначе музыкальный OGG попадёт в WAV-загрузчик.

### Код загрузки и отрисовки для вставки

`LevelDecals.cs` создаётся целиком. Вставки в `Level.cs` также освобождают временные данные капсульной коллизии из первого раздела.

#### Создай `Levels/LevelDecals.cs`

~~~csharp
using System.Text.Json;
using System.Text.Json.Serialization;
using _3DLight.Collision;
using Ars3D.ModelFormat;
using Ars3D.Rendering;
using Microsoft.Xna.Framework;
using Microsoft.Xna.Framework.Graphics;
using NumericsVector2 = System.Numerics.Vector2;
using NumericsVector3 = System.Numerics.Vector3;

namespace _3DLight;

internal sealed class LevelDecals : IDisposable
{
    // Допуск выбирает треугольники одной поверхности, а отступ убирает мерцание от совпадения глубины.
    private const float SurfaceTolerance = 0.025f;
    private const float SurfaceOffset = 0.003f;
    private readonly List<CompiledModel> models = [];
    private readonly Dictionary<(string File, bool WhiteBackground), Texture2D> textures = [];

    public static LevelDecals? Load(GraphicsDevice graphics, Effect effect, string levelName,
        ModelData data, ModelHierarchy hierarchy)
    {
        string content = Path.Combine(AppContext.BaseDirectory, "Content");
        string path = Path.Combine(content, "Levels", levelName + ".decals.json");
        if (!File.Exists(path))
            return null;

        DecalDefinition[] entries = ReadDefinitions(path);
        ILookup<string, Level.TriangleCollider> receivers = FindReceivers(entries, data, hierarchy);
        string textureDirectory = Path.Combine(content, "Decals");
        var decals = new LevelDecals();
        try
        {
            foreach (DecalDefinition entry in entries)
                decals.AddDecal(graphics, effect, textureDirectory, entry, receivers[entry.Node]);
            return decals;
        }
        catch
        {
            decals.Dispose();
            throw;
        }
    }

    private void AddDecal(GraphicsDevice graphics, Effect effect, string textureDirectory,
        DecalDefinition entry, IEnumerable<Level.TriangleCollider> triangles)
    {
        MeshData? mesh = Project(entry, triangles);
        if (mesh is null)
        {
            string position = string.Join(", ", entry.Position);
            Console.WriteLine($"Декаль '{entry.Texture}': в точке [{position}] узла '{entry.Node}' нет поверхности.");
            return;
        }

        Texture2D texture = GetTexture(graphics, textureDirectory, entry);
        models.Add(ModelAssetLoader.CreateDecal(graphics, mesh, texture, effect));
    }

    private static DecalDefinition[] ReadDefinitions(string path)
    {
        var options = new JsonSerializerOptions
        {
            PropertyNameCaseInsensitive = true,
            UnmappedMemberHandling = JsonUnmappedMemberHandling.Disallow
        };
        var entries = JsonSerializer.Deserialize<DecalDefinition[]>(File.ReadAllText(path), options)
            ?? throw new InvalidDataException($"Пустая конфигурация декалей: {path}");

        foreach (DecalDefinition entry in entries)
        {
            if (entry is null)
                throw new InvalidDataException($"Пустая запись в {path}.");
            entry.Validate();
        }
        return entries;
    }

    private static ILookup<string, Level.TriangleCollider> FindReceivers(
        DecalDefinition[] entries, ModelData data, ModelHierarchy hierarchy)
    {
        var nodes = entries.Select(entry => entry.Node).ToHashSet(StringComparer.OrdinalIgnoreCase);
        var meshIds = Enumerable.Range(0, data.Meshes.Count)
            .Where(index => nodes.Contains(data.Nodes[data.Meshes[index].Node].Name)).ToHashSet();
        // Берём треугольники указанных узлов в исходной позе уровня.
        return LevelGeometryBuilder.BuildTriangleColliders(data, hierarchy.BindPoseGlobalTransforms, meshIds)
            .ToLookup(triangle => triangle.Name, StringComparer.OrdinalIgnoreCase);
    }

    private static MeshData? Project(DecalDefinition entry, IEnumerable<Level.TriangleCollider> triangles)
    {
        if (FindSurface(entry, triangles) is not { } surface)
            return null;

        Vector3 halfSize = new(entry.Size[0] / 2f, entry.Size[1] / 2f, SurfaceTolerance);
        BoundingBox bounds = surface.GetBounds(halfSize);
        var vertices = new List<VertexData>();
        var indices = new List<int>();
        foreach (Level.TriangleCollider triangle in triangles)
        {
            if (!triangle.Bounds.Intersects(bounds))
                continue;
            bool parallelToSurface = MathF.Abs(Vector3.Dot(triangle.Normal, surface.Normal)) >= 0.95f;
            if (!parallelToSurface)
                continue;

            List<Vector3> polygon = ClipTriangle(triangle, surface, halfSize);
            AppendPolygon(polygon, surface, entry.Size, vertices, indices);
        }

        return indices.Count == 0 ? null : new MeshData
        {
            Name = entry.Texture,
            Vertices = vertices.ToArray(),
            Indices = indices.ToArray(),
            MaterialOpacity = entry.Opacity
        };
    }

    private static SurfaceFrame? FindSurface(DecalDefinition entry, IEnumerable<Level.TriangleCollider> triangles)
    {
        Vector3 position = ToVector3(entry.Position);
        Vector3 direction = Vector3.Normalize(ToVector3(entry.Normal));
        // Начинаем снаружи стены и направляем луч внутрь по заданной нормали.
        var ray = new Ray(position + direction * entry.ProjectionDistance, -direction);
        float nearest = 2f * entry.ProjectionDistance;
        Vector3 normal = Vector3.Zero;
        foreach (Level.TriangleCollider triangle in triangles)
        {
            float alignment = Vector3.Dot(triangle.Normal, direction);
            if (MathF.Abs(alignment) < 0.5f)
                continue;
            if (Level.RayHit(ray, triangle) is not { } hit || hit >= nearest)
                continue;

            nearest = hit;
            normal = alignment > 0f ? triangle.Normal : -triangle.Normal;
        }

        if (normal == Vector3.Zero)
            return null;

        Vector3 center = ray.Position + ray.Direction * nearest;
        Vector3 referenceUp = MathF.Abs(normal.Y) < 0.99f ? Vector3.Up : Vector3.Forward;
        Vector3 right = Vector3.Normalize(Vector3.Cross(referenceUp, normal));
        return new SurfaceFrame(center, normal, right, Vector3.Cross(normal, right));
    }

    private static List<Vector3> ClipTriangle(Level.TriangleCollider triangle, SurfaceFrame surface, Vector3 half)
    {
        // В локальных координатах обрезаем треугольник шестью сторонами области проекции.
        List<Vector3> polygon = [surface.ToLocal(triangle.A), surface.ToLocal(triangle.B), surface.ToLocal(triangle.C)];
        polygon = Clip(polygon, Vector3.Right, half.X);
        polygon = Clip(polygon, Vector3.Left, half.X);
        polygon = Clip(polygon, Vector3.Up, half.Y);
        polygon = Clip(polygon, Vector3.Down, half.Y);
        polygon = Clip(polygon, Vector3.Backward, half.Z);
        return Clip(polygon, Vector3.Forward, half.Z);
    }

    private static void AppendPolygon(List<Vector3> polygon, SurfaceFrame surface, float[] size,
        List<VertexData> vertices, List<int> indices)
    {
        if (polygon.Count < 3)
            return;

        int first = vertices.Count;
        foreach (Vector3 point in polygon)
        {
            Vector3 world = surface.ToWorld(point) + SurfaceOffset * surface.Normal;
            var uv = new NumericsVector2(point.X / size[0] + 0.5f, 0.5f - point.Y / size[1]);
            // Шейдер использует единичную матрицу первой кости для статических вершин.
            vertices.Add(new VertexData(ToNumerics(world), ToNumerics(surface.Normal), uv,
                0, 0, 0, 0, System.Numerics.Vector4.UnitX));
        }
        for (int i = 1; i + 1 < polygon.Count; i++)
        {
            indices.Add(first);
            indices.Add(first + i);
            indices.Add(first + i + 1);
        }
    }

    private readonly record struct SurfaceFrame(Vector3 Center, Vector3 Normal, Vector3 Right, Vector3 Up)
    {
        public Vector3 ToLocal(Vector3 point)
        {
            Vector3 relative = point - Center;
            return new(Vector3.Dot(relative, Right), Vector3.Dot(relative, Up), Vector3.Dot(relative, Normal));
        }

        public Vector3 ToWorld(Vector3 point) => Center + point.X * Right + point.Y * Up + point.Z * Normal;

        public BoundingBox GetBounds(Vector3 half)
        {
            Vector3 extent = Vector3.Max(Right, -Right) * half.X +
                Vector3.Max(Up, -Up) * half.Y + Vector3.Max(Normal, -Normal) * half.Z;
            return new BoundingBox(Center - extent, Center + extent);
        }
    }

    private static List<Vector3> Clip(List<Vector3> polygon, Vector3 axis, float limit)
    {
        if (polygon.Count == 0)
            return polygon;

        var result = new List<Vector3>(polygon.Count + 1);
        Vector3 previous = polygon[^1];
        float previousDistance = limit - Vector3.Dot(previous, axis);
        foreach (Vector3 current in polygon)
        {
            float distance = limit - Vector3.Dot(current, axis);
            if ((distance >= 0f) != (previousDistance >= 0f))
                result.Add(Vector3.Lerp(previous, current, previousDistance / (previousDistance - distance)));
            if (distance >= 0f)
                result.Add(current);
            previous = current;
            previousDistance = distance;
        }
        return result;
    }

    private Texture2D GetTexture(GraphicsDevice graphics, string folder, DecalDefinition entry)
    {
        var key = (entry.Texture, entry.WhiteBackground);
        if (textures.TryGetValue(key, out Texture2D? texture))
            return texture;

        using FileStream stream = File.OpenRead(Path.Combine(folder, entry.Texture));
        texture = Texture2D.FromStream(graphics, stream);
        try
        {
            if (entry.WhiteBackground)
                ApplyInkMask(texture);
            textures.Add(key, texture);
            return texture;
        }
        catch
        {
            texture.Dispose();
            throw;
        }
    }

    private static void ApplyInkMask(Texture2D texture)
    {
        // Для одноцветного рисунка яркость фона превращаем в прозрачность.
        var pixels = new Color[texture.Width * texture.Height];
        texture.GetData(pixels);
        for (int i = 0; i < pixels.Length; i++)
        {
            Color source = pixels[i];
            int brightness = (source.R * 54 + source.G * 183 + source.B * 19) / 256;
            pixels[i] = new Color(0, 0, 0, (255 - brightness) * source.A / 255);
        }
        texture.SetData(pixels);
    }

    public void Draw(Matrix view, Matrix projection, SceneLighting lighting, SceneRenderQueue? queue)
    {
        foreach (CompiledModel model in models)
            model.Draw(Matrix.Identity, view, projection, lighting, queue);
    }

    public void Dispose()
    {
        // Модели ссылаются на общие текстуры, поэтому освобождаем текстуры после моделей.
        foreach (CompiledModel model in models)
            model.Dispose();
        foreach (Texture2D texture in textures.Values)
            texture.Dispose();
    }

    private static Vector3 ToVector3(float[] values) => new(values[0], values[1], values[2]);
    private static NumericsVector3 ToNumerics(Vector3 value) => new(value.X, value.Y, value.Z);

    private sealed class DecalDefinition
    {
        public string Node { get; init; } = "";
        public string Texture { get; init; } = "";
        public float[] Position { get; init; } = [];
        public float[] Normal { get; init; } = [];
~~~

### Почему декаль ложится на стену

`LevelDecals` берёт треугольники выбранного узла, лучом находит поверхность рядом с `position`, строит на ней локальные оси и обрезает треугольники по границам картинки. Поэтому у края стены обрезается и декаль. Сдвиг вдоль нормали на `0.003` отделяет её от поверхности, чтобы они не мерцали из-за одинаковой глубины. Прозрачный проход учитывает глубину уже нарисованной стены и смешивает знак с её материалом. Для статических вершин используется единичный вес преобразования, которого ожидает общий шейдер модели.

**Проверка.** Посмотри на левую наружную стену примерно из `[-5, 1.75, -17]` и правую из `[13.5, 1.75, -25.8]`. Если в журнале написано «нет поверхности», проверь имя узла, приблизительный центр и сторону нормали. Если знак обрезан, сдвинь его центр с края стены. Текущая реализация проецирует на статическую геометрию в исходной позе. Для двери, которая поворачивается, нужно привязывать декаль к преобразованию двери.

## Что проверять после переноса

В Visual Studio выбери **Сборка → Собрать решение**, затем запусти игру через **F5**. Если начал со штатной модели `gun`, проверка патронов и перезарядки работает и до импорта длинной модели.

1. Главный экран загружается, OGG играет, три ползунка влияют на свои каналы.
2. В первом слоте видна винтовка, выстрел и перезарядка меняют счётчик. После выбрасывания и подбора патроны сохраняются.
3. Брошенный фонарик и винтовка сталкиваются с полом и стеной. Декали при этом остаются визуальной частью стены.
4. На двух противоположных стенах есть сигили с прозрачным фоном. При закрытии диалога `Esc` обрабатывается как закрытие, а следующее отдельное нажатие переключает паузу.
