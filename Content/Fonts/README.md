# Old Standard TT

The inventory, pickup prompt and menu use **Old Standard TT Regular** by
Alexey Kryukov / The Old Standard Project Authors. It is a ready-made serif
typeface with Latin and Cyrillic characters, distributed under the SIL Open
Font License 1.1. The font file is unmodified.

Official source: <https://github.com/google/fonts/tree/main/ofl/oldstandardtt>

Font download: <https://raw.githubusercontent.com/google/fonts/main/ofl/oldstandardtt/OldStandard-Regular.ttf>

License: `OFL.txt`, copied alongside the compiled content during the build.

`OldStandardText.spritefont` sets the inventory and prompt size to 14 points;
`OldStandardMenu.spritefont` sets menu labels to 22 points. Both reference the
adjacent TTF, so building the game does not require installing a system font.
