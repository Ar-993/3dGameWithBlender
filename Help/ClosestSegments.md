# `ClosestSegments`: поиск ближайших точек между двумя отрезками

## Назначение

Метод `ClosestSegments` находит две точки с минимальным расстоянием между двумя конечными отрезками в трёхмерном пространстве.

В капсульном коллайдере первый отрезок — центральная ось капсулы, а второй — ребро треугольника уровня. Метод возвращает:

- `onA` — ближайшую точку на оси капсулы;
- `onB` — ближайшую точку на ребре треугольника.

После этого расстояние между `onA` и `onB` сравнивается с радиусом капсулы. Если оно меньше суммы радиуса и защитного зазора, капсула касается ребра или пересекает его.

```csharp
private static void ClosestSegments(
    Vector3 a0,
    Vector3 a1,
    Vector3 b0,
    Vector3 b1,
    out Vector3 onA,
    out Vector3 onB)
{
    Vector3 a = a1 - a0;
    Vector3 b = b1 - b0;
    Vector3 offset = a0 - b0;
    float aa = Vector3.Dot(a, a);
    float bb = Vector3.Dot(b, b);
    float bo = Vector3.Dot(b, offset);
    float s, t;

    if (aa <= Tiny && bb <= Tiny)
    {
        onA = a0;
        onB = b0;
        return;
    }

    if (aa <= Tiny)
    {
        s = 0f;
        t = MathHelper.Clamp(bo / bb, 0f, 1f);
    }
    else
    {
        float ao = Vector3.Dot(a, offset);
        if (bb <= Tiny)
        {
            t = 0f;
            s = MathHelper.Clamp(-ao / aa, 0f, 1f);
        }
        else
        {
            float ab = Vector3.Dot(a, b);
            float denominator = aa * bb - ab * ab;
            s = denominator > Tiny
                ? MathHelper.Clamp((ab * bo - ao * bb) / denominator, 0f, 1f)
                : 0f;
            t = (ab * s + bo) / bb;

            if (t < 0f)
            {
                t = 0f;
                s = MathHelper.Clamp(-ao / aa, 0f, 1f);
            }
            else if (t > 1f)
            {
                t = 1f;
                s = MathHelper.Clamp((ab - ao) / aa, 0f, 1f);
            }
        }
    }

    onA = a0 + a * s;
    onB = b0 + b * t;
}
```

## Параметрическое представление отрезков

Первый отрезок задан концами `a0` и `a1`, второй — концами `b0` и `b1`.

```text
a0 ●────────────● a1

b0 ●────────────● b1
```

Направления отрезков вычисляются вычитанием их концов:

```csharp
Vector3 a = a1 - a0;
Vector3 b = b1 - b0;
```

Любую точку первого отрезка можно описать параметром `s`:

```text
P(s) = a0 + a × s
```

Любую точку второго отрезка — параметром `t`:

```text
Q(t) = b0 + b × t
```

Значения параметров означают:

| Параметр | Положение на отрезке |
|---:|---|
| `0` | начало |
| `0.5` | середина |
| `1` | конец |

Следовательно, задача метода — найти такие `s` и `t` в диапазоне от `0` до `1`, чтобы расстояние между `P(s)` и `Q(t)` было минимальным.

## Смещение между отрезками

```csharp
Vector3 offset = a0 - b0;
```

`offset` — вектор от начала второго отрезка к началу первого. Он появляется при вычитании произвольных точек отрезков:

```text
P(s) - Q(t)
= a0 + a×s - b0 - b×t
= offset + a×s - b×t
```

Именно длину этого вектора метод минимизирует.

## Что означает `Vector3.Dot`

Скалярное произведение вычисляется так:

```text
Dot(x, y) = x.X×y.X + x.Y×y.Y + x.Z×y.Z
```

Оно показывает, насколько один вектор направлен вдоль другого:

- положительное значение — направления в основном совпадают;
- отрицательное значение — направления в основном противоположны;
- ноль — векторы перпендикулярны.

Скалярное произведение вектора с самим собой равно квадрату его длины:

```text
Dot(a, a) = |a|²
```

Поэтому переменные:

```csharp
float aa = Vector3.Dot(a, a);
float bb = Vector3.Dot(b, b);
```

означают:

```text
aa = квадрат длины отрезка A
bb = квадрат длины отрезка B
```

Квадрат длины позволяет проверить вырожденность отрезка без вычисления квадратного корня.

Остальные сокращения означают:

```csharp
float bo = Vector3.Dot(b, offset);
float ao = Vector3.Dot(a, offset);
float ab = Vector3.Dot(a, b);
```

```text
bo — проекция смещения на направление B;
ao — проекция смещения на направление A;
ab — взаимное направление A и B.
```

## Почему ближайший соединяющий вектор перпендикулярен отрезкам

Для двух бесконечных непараллельных прямых кратчайший соединяющий их вектор перпендикулярен обеим прямым. Если бы он имел составляющую вдоль одной из прямых, соответствующую точку можно было бы передвинуть и ещё уменьшить расстояние.

Обозначим соединяющий вектор через:

```text
D = P(s) - Q(t)
```

В ближайшей паре точек выполняются условия:

```text
Dot(D, a) = 0
Dot(D, b) = 0
```

Подстановка `D = offset + a×s - b×t` даёт систему двух уравнений. Её решение приводит к формулам для `s` и `t`, используемым в методе.

## Обычный случай: оба отрезка имеют длину

```csharp
float ab = Vector3.Dot(a, b);
float denominator = aa * bb - ab * ab;
```

`denominator` показывает, можно ли устойчиво решить систему для двух прямых. Если направления параллельны или почти параллельны, значение близко к нулю.

Например, для параллельных направлений:

```text
a = (0, 2, 0)
b = (0, 5, 0)

aa = 4
bb = 25
ab = 10
denominator = 4×25 - 10² = 0
```

Для перпендикулярных единичных направлений:

```text
a = (1, 0, 0)
b = (0, 1, 0)

aa = 1
bb = 1
ab = 0
denominator = 1
```

Если отрезки не параллельны, первичное значение `s` рассчитывается так:

```csharp
s = MathHelper.Clamp(
    (ab * bo - ao * bb) / denominator,
    0f,
    1f);
```

Это решение условия минимального расстояния для точки на первом отрезке. `Clamp` ограничивает результат настоящим конечным отрезком:

- `s < 0` превращается в `0`, то есть в `a0`;
- `s > 1` превращается в `1`, то есть в `a1`.

Если направления почти параллельны, деление на `denominator` было бы неустойчивым. Тогда берётся начало первого отрезка:

```csharp
s = 0f;
```

После выбора `s` вычисляется ближайшее положение на линии второго отрезка:

```csharp
t = (ab * s + bo) / bb;
```

Эта формула является проекцией вектора от `b0` до выбранной точки `P(s)` на направление `b`.

## Почему `t` корректируется после вычисления

Первичный результат `t` относится к бесконечной линии. У конечного отрезка допустим только диапазон от `0` до `1`.

Если `t < 0`, ближайшая точка линии находится перед `b0`:

```csharp
t = 0f;
s = MathHelper.Clamp(-ao / aa, 0f, 1f);
```

Точка `Q` фиксируется в `b0`, после чего заново находится ближайшая к `b0` точка отрезка A.

Если `t > 1`, ближайшая точка линии находится после `b1`:

```csharp
t = 1f;
s = MathHelper.Clamp((ab - ao) / aa, 0f, 1f);
```

Точка `Q` фиксируется в `b1`, после чего заново находится ближайшая к `b1` точка отрезка A.

Пересчёт `s` необходим: первоначальное значение было найдено для пары прямых, а после фиксации точки на конце B задача изменилась.

## Вырожденные отрезки

Константа `Tiny` задаёт порог «практически нулевого» значения:

```csharp
private const float Tiny = 0.000000000001f;
```

Сравнение выполняется с квадратом длины, поэтому отрезок считается точкой, когда его длина примерно не превышает `0.000001` единицы.

### Оба отрезка являются точками

```csharp
if (aa <= Tiny && bb <= Tiny)
{
    onA = a0;
    onB = b0;
    return;
}
```

Если оба отрезка практически не имеют длины, ближайшими точками являются их начала.

### Только первый отрезок является точкой

```csharp
if (aa <= Tiny)
{
    s = 0f;
    t = MathHelper.Clamp(bo / bb, 0f, 1f);
}
```

Точка на A фиксируется в `a0`, а на B выбирается проекция `a0`, ограниченная концами B.

### Только второй отрезок является точкой

```csharp
if (bb <= Tiny)
{
    t = 0f;
    s = MathHelper.Clamp(-ao / aa, 0f, 1f);
}
```

Точка на B фиксируется в `b0`, а на A выбирается проекция `b0`, ограниченная концами A.

Эти проверки предотвращают деление на почти нулевую длину и появление `NaN` или огромной численной ошибки.

## Получение итоговых координат

Когда допустимые `s` и `t` найдены, они преобразуются в реальные точки:

```csharp
onA = a0 + a * s;
onB = b0 + b * t;
```

Например:

```text
a0 = (0, 0, 0)
a1 = (0, 4, 0)
s  = 0.5

onA = (0, 0, 0) + (0, 4, 0)×0.5
onA = (0, 2, 0)
```

## Пример с пересекающимися отрезками

```text
a0 = (0, 0, 0)
a1 = (0, 4, 0)

b0 = (-2, 2, 0)
b1 = ( 2, 2, 0)
```

Схема:

```text
       a1
       ●
       │
b0 ●───┼───● b1
       │
       ●
       a0
```

Результат:

```text
onA = (0, 2, 0)
onB = (0, 2, 0)
distance = 0
```

## Пример для капсулы и ребра треугольника

Пусть ось капсулы задана так:

```text
a0 = (0, 0.35, 0)
a1 = (0, 1.45, 0)
```

Ребро треугольника:

```text
b0 = (0.5, 0, -1)
b1 = (0.5, 0,  1)
```

Ближайшими точками будут примерно:

```text
onA = (0,   0.35, 0)
onB = (0.5, 0,    0)
```

Расстояние между ними:

```text
distance = √(0.5² + 0.35²)
distance ≈ 0.6103
```

При радиусе капсулы `0.35` столкновения нет. Если ребро приблизится настолько, что расстояние станет меньше `Radius + SkinWidth`, будет зарегистрирован контакт.

## Роль функции в полном поиске контакта

`ClosestSegments` проверяет только пару «ось капсулы — ребро треугольника». Внешний метод `ClosestSegmentTriangle` дополнительно рассматривает:

- пересечение оси с внутренней областью треугольника;
- ближайшую точку треугольника к нижнему концу оси;
- ближайшую точку треугольника к верхнему концу оси;
- каждое из трёх рёбер треугольника через `ClosestSegments`.

Из всех кандидатов выбирается пара с минимальным расстоянием. Поэтому итоговый контакт учитывает плоскость треугольника, его рёбра и вершины.

## Краткое резюме

`ClosestSegments` выполняет следующую последовательность:

1. Представляет точки отрезков параметрами `s` и `t`.
2. Через скалярные произведения получает длины и взаимные направления.
3. Решает задачу минимального расстояния между двумя прямыми.
4. Ограничивает найденные точки концами реальных отрезков.
5. Отдельно обрабатывает точки и почти параллельные отрезки.
6. Возвращает реальные координаты ближайших точек в `onA` и `onB`.

Главная математическая идея:

```text
Найти s и t в диапазоне [0, 1],
при которых |P(s) - Q(t)| минимально.
```

Главная роль в коллизиях:

```text
ось капсулы ↔ ребро треугольника
            ↓
     минимальное расстояние
            ↓
сравнение с радиусом капсулы
```
