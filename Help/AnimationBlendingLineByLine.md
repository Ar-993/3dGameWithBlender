# Плавное смешивание анимаций: построчный разбор

Этот документ объясняет все строки кода, добавленные или содержательно изменённые при внедрении cross-fade-анимаций. Номера соответствуют текущим версиям файлов после реализации.

Строки, содержащие только `{` или `}`, соответственно открывают и закрывают описанный рядом блок. Пустые строки разделяют логические части и во время выполнения ничего не делают. Если один вызов или объявление разбито форматированием на несколько строк, ниже объяснена каждая его часть.

## Общая схема

Каждый кадр теперь проходит так:

1. Игровая логика выбирает целевой клип через `Play`.
2. Ровно один вызов `Update` продвигает время клипа и перехода.
3. `CompiledModel.SamplePose` получает локальную TRS-позу каждого узла для нужного момента клипа.
4. Во время перехода исходная и целевая позы смешиваются по каждой кости.
5. Смешанная локальная поза превращается в матрицы, затем в глобальные матрицы скелета и отправляется в шейдер.

TRS означает `Translation`, `Rotation`, `Scale`: положение, вращение и масштаб. Положение и масштаб смешиваются через `Lerp`, вращение — через `Slerp`. Матрицы напрямую не интерполируются, потому что это может добавить сдвиг осей, неправильный масштаб и деформацию.

## Почему прерванный переход не дёргается

Пусть идёт переход `Run → Attack`, и до его завершения начинается `Hurt`. В этот момент код не использует чистую позу `Run` или чистую позу `Attack`. Строка 127 `CharacterAnimator.cs` вычисляет фактически видимую смесь `Run/Attack`, сохраняет её и начинает `snapshot → Hurt`. Поэтому первая поза нового перехода математически совпадает с последней позой предыдущего, а скачок отсутствует.

## Где настраивать скорость blend

Автоматические значения находятся в `ResolveBlendDuration`:

- `Idle ↔ Run`: 0,20 секунды;
- `Landing → Run`: 0,06 секунды;
- переход в `Jump`, `Falling`, `FallingBad` или `Landing`: 0,10 секунды;
- переход в `Hurt` или `Die`: 0,08 секунды;
- остальные переходы: 0,15 секунды.

Для конкретного вызова можно передать `blendDuration` напрямую в `CharacterAnimator.Play`. Ноль означает мгновенное переключение.
