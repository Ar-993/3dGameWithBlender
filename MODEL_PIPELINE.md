# Модели Ars3D

## Схема

`FBX -> Tools/ModelCompiler (Assimp) -> .3dmodel -> CompiledModel -> GPU`

Игра не читает FBX. Перед каждой сборкой отдельный компилятор создаёт:

- `level.3dmodel` — уровень и геометрия платформ;
- `player.3dmodel` — Rogue и все его клипы;
- `skeleton.3dmodel` — Skeleton и все его клипы.

MGCB собирает только текстуры и шрифт. В runtime нет зависимости Assimp.

Формат `.3dmodel` версии 3 сохраняет имя материала и его прозрачность из FBX.
Старые файлы версии 2 также читаются. Чтобы применить изменение Alpha в Blender,
сохраните `.blend`, экспортируйте FBX и пересоберите игру: компилятор перенесёт
параметр в модель. Шейдер умножает альфу текстуры на альфу материала; стекло
рисуется с текстурой в проходе прозрачности, а рамы со своим непрозрачным материалом.

## Коллизии уровня

Все меши FBX уровня с треугольной геометрией автоматически участвуют в коллизиях:
стены, пол, крыши, башни, окна, двери и декор. Имена объектов и материалов не
влияют на включение коллайдера; переименовывать объекты в `Wall` или `Floor` не нужно.

Персонаж использует вертикальную 3D-капсулу: `Position` задаёт низ, `Height`
включает полусферы, а концы оси расположены на высотах `Radius` и
`Height - Radius`. Расстояние от отрезка оси до треугольника учитывает грани,
рёбра и вершины. На краю пола округлые ноги могут опуститься ниже плоскости
пола; это геометрия капсулы, а не пропущенная коллизия.

`Collision/CapsuleCollision.cs` выполняет непрерывный поиск контакта вдоль
каждого перемещения с зазором 0.001. `Level.CharacterCollision.cs` сначала
обрабатывает горизонтальное движение, затем вертикальное. Он сохраняет
контактные плоскости для скольжения в углах и восстанавливает позицию при
начальном пересечении. Для ступени проверяется путь вверх, вперёд и вниз
всей капсулой; максимальный подъём — 0.55 единицы. Крутые поверхности не
становятся опорой, а на пологих используется проверка капсулы вниз.

Empty, точки появления и другие узлы без меша не создают коллайдеров. Режим
`O` показывает грани всех коллайдеров и капсулы персонажей с полусферами.
`FirstPersonCamera` находится внутри невидимой капсулы игрока на высоте глаз
1.62. `FirstPersonController` отвечает за WASD и прыжок; модель Rogue в игре
для локального игрока не загружается. После изменения FBX пересоберите модель
или загрузите новую версию через существующий hot reload.

## Подбираемые предметы

Физика и логика предметов в мире и в руке вынесены в самостоятельный проект
`Libraries/Ars3D.Items`. Он использует только .NET 8 и `System.Numerics`.
`ItemDefinition` хранит общие характеристики типа, `ItemInstance` — отдельное
состояние, `SingleSlotInventory` — один скрытый слот, а
`ItemInteractionController` — подбор и бросок. Физика игрока и камера остаются
в игре.

В игре `Items/ItemCatalog.cs` читает `Content/Items/items.json` и повторно
использует одну модель для экземпляров одного типа. Запись `spawns` связывает
ID типа с Empty уровня. Сейчас Empty `ItemSpawn` задаёт начальную позицию
Деда Мороза из `Christmas.rar`; `ItemSpawner` находит маркер и создаёт
экземпляр через каталог. Для нового типа добавляются модель, текстуры и запись
каталога; отдельный класс предмета не нужен.

`Physics/RigidBody.cs` внутри библиотеки представляет одно твёрдое тело.
Форма, движение, поиск контактов, реакция на столкновения, шаги времени и покой
разделены между небольшими классами. `RigidBodySettings` задаёт параметры
физики; `physics` и `spawnSpin` в каталоге задают падение и начальное вращение.
Внутри каждого определения предмета `interaction` задаёт смещение в руке,
подъём и вращение при броске. Дистанция подбора и скорость броска находятся в
`Content/Player/player.json`. `PlayerDefinition.Load()` напрямую читает этот
файл; `Player` хранит полученное определение в `Definition`, а контроллер
предметов получает настройки через `player.Definition.Interaction`.
Кости и конечности сохраняют позу модели: весь предмет вращается вокруг
центра массы, получает импульсы при ударах и может остановиться на боку.

`Items/LevelItemWorld.cs` реализует интерфейс окружения библиотеки через
`Level.RigidItemCollision.cs`: сферические части округлой формы проверяются
по треугольникам уровня, в том числе при вращении. Размер формы берётся из
нормализованных границ модели. `WorldItem` и `ItemModelRenderer` связывают
состояние с отрисовкой; `ItemModelTransform` учитывает статические и скелетные
преобразования импортированной модели.

Только рядом с доступным предметом UI показывает одну строку
`[E] ВЗЯТЬ ДЕДА МОРОЗА` пиксельным шрифтом PSX. Нажатие E занимает скрытый
слот; следующее нажатие бросает вещь по направлению взгляда. Подбор через
стены запрещён, а при удержании подсказка скрыта. Поворот вещи в руке задаёт
`heldYawDegrees` в определении типа.

Полное подключение, места вставок, готовые примеры и проверки описаны в
[пошаговой инструкции](Help/ItemSystemStepByStep.md).

## Новая статическая модель

Добавьте FBX и запись в `Assets/models.json`:

```json
{
  "name": "crate",
  "source": "../Content/Assets/Props/crate.fbx",
  "output": "../Content/Models/crate.3dmodel"
}
```

После `dotnet build` загрузите её через:

```csharp
CompiledModel model = CompiledModel.Load(graphicsDevice, "crate", texture);
model.Draw(world, view, projection);
```

## Новый персонаж

`source` должен содержать основной меш и эталонный скелет. В `clips` указываются FBX того же скелета:

```json
{
  "name": "enemy",
  "source": "../Content/Assets/Enemy/EnemyTPose.fbx",
  "output": "../Content/Models/enemy.3dmodel",
  "clips": {
    "Idle": "../Content/Assets/Enemy/EnemyIdle.fbx",
    "Run": "../Content/Assets/Enemy/EnemyRun.fbx"
  }
}
```

Имена костей должны совпадать. Лимиты MonoGame `SkinnedEffect`: 72 кости на меш и четыре веса на вершину.

## Новый клип Skeleton

1. Положите FBX в папку персонажа.
2. Добавьте клип в `clips` соответствующей модели в `Assets/models.json`.
3. Добавьте такое же имя в словарь `Skeleton.cs`.
4. Выполните `dotnet build`.
5. В логике вызовите `Play("Имя", loop, deltaTime)`.

Ручная компиляция без полной сборки:

```powershell
dotnet run --project Tools\ModelCompiler\ModelCompiler.csproj -- Assets\models.json
```
