# Предметы: карта кода

Библиотека использует только .NET и System.Numerics. Ввод, отрисовка и геометрия
уровня остаются в игре. Связные операции собраны в десяти исходных файлах.

Начни с первых трёх файлов:

| Файл | Что читать в нём |
| --- | --- |
| `ItemDefinition.cs` | Описание типа предмета и его настройки удержания/броска `ItemCarrySettings`. |
| `ItemInstance.cs` | Состояние экземпляра, подбор/выпуск, публичные свойства тела и структура `ItemPose`. |
| `ItemInteractionController.cs` | Полный сценарий: кнопка → поиск → подбор → слот → положение в руке → бросок. Внизу — `ItemInteractionSettings`. |
| `Physics/RigidBody.cs` | Состояние тела, шаги времени, силы, инерция, затухание, сон и пробуждение. |
| `Physics/RigidBodySettings.cs` | Числовые настройки физики. |
| `Physics/BodyCollision.cs` | Поиск первого столкновения, движение до него и устранение проникновений. |
| `Physics/ContactSolver.cs` | Импульсы контактов: отскок, вращение и трение. |
| `Physics/RoundedBoxShape.cs` | Форма тела, сферы для запросов столкновений и расчёт границ. |
| `Physics/Collision/ICollisionWorld.cs` | Четыре геометрических запроса к игре, а также результаты `BodyContact` и `SweepHit`. |
| `Geometry/Aabb.cs` | Ограничивающий параллелепипед и ближайшая к нему точка. |

Обычный путь выполнения:

```text
ItemInteractionController.Update
  → ItemInstance.UpdatePhysics
    → RigidBody.Update
      → BodyCollision: найти столкновение
      → ContactSolver: обработать контакт
  → найти доступный предмет
  → по новому нажатию подобрать или бросить
```

Контроллер сам хранит `HeldItem`. Для прямого подбора есть
`controller.TryPickUp(item)`; отдельного объекта инвентаря больше нет.
Для отрисовки удерживаемого предмета используется `GetHeldPose`.
При броске берётся тот же расчёт положения, поэтому предмет не перескакивает.

Внутри классов расчёты остаются отдельными короткими методами. Для чтения
одного действия не требуется переходить между вспомогательными классами.

Проверки библиотеки:

```powershell
dotnet run --project Libraries/Ars3D.Items.Tests/Ars3D.Items.Tests.csproj
```
